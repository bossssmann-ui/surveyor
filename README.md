# ГеоПримор — Геодезические изыскания в Приморском крае

Сайт-визитка для привлечения клиентов, нуждающихся в геодезических изысканиях на территории Приморского края и г. Находка.

## Описание

Одностраничный лендинг с информацией о геодезических услугах:

- **Топографическая съёмка** — создание топографических планов и карт
- **Межевание участков** — определение и уточнение границ земельных участков
- **Кадастровые работы** — подготовка технических и межевых планов
- **Инженерные изыскания** — комплексные инженерно-геодезические изыскания
- **Вынос границ в натуру** — перенос проектных точек на местность
- **Геодезический контроль** — сопровождение строительства

## Эскизы страниц

Визуальные эскизы всех секций сайта доступны на отдельной странице:

- **В браузере:** откройте [`sketches.html`](sketches.html)
- **В Markdown:** смотрите [`SKETCHES.md`](SKETCHES.md)

## Структура

```
index.html          — главная страница
sketches.html       — галерея эскизов страниц
css/style.css       — стили
js/main.js          — скрипты (мобильное меню, форма, анимации)
wireframes/         — SVG каркасные эскизы (wireframes) секций
screenshots/        — скриншоты реализации (десктоп + мобильная версия)
SKETCHES.md         — документация эскизов в Markdown
```

## Запуск

Откройте `index.html` в браузере. Дополнительные зависимости не требуются.

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, адаптивный дизайн)
- Vanilla JavaScript
